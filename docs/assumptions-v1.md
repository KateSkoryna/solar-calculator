# Assumption set v1 (version 2026.1)

Every number the calculator needs but the user does not enter. Each value has a pessimistic, realistic and optimistic scenario. **Higher** or **lower** in the code (`favourableDirection`) says which direction makes solar look better, so the pessimistic value is always the unfavourable one.

The values live in `lib/assumptions/` (`v1.ts` and `eu-countries.ts`). The Key column is the exact TypeScript path in `ASSUMPTION_SET_V1`. All sources were accessed on 2026-09-30.

Totals: 235 values, 171 backed by a source and 64 marked `ASSUMPTION`.

## Ranges

- Fuel, electricity, grid CO2 and yields use observed ranges (see the note of each row). Pessimistic and optimistic are the observed lowest and highest, or one standard deviation.
- Values marked `ASSUMPTION` have no public source. The reasoning is in the note and each one needs an owner review.

## Defaults and gaps

- Typical cooling unit when chilled: van `ENGINE_DRIVEN`, truck and trailer `DIESEL`, bus `ELECTRIC`. This is an assumption.
- Subsidies: no public subsidy for vehicle-mounted solar panels was verified in any EU country, so every country has an empty list. A Dutch subsidy for solar-equipped refrigerated trailers is mentioned in trade press but no scheme name, amount or source was found. Users can enter their own amount.
- The Oil Bulletin lists a fuel VAT rate of 8% for Poland. It is used as published.
- Diesel prices are without VAT because VAT-registered businesses can reclaim it.
